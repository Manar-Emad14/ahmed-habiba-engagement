# 💍 دعوة خطوبة أحمد & حبيبة (Ahmed & Habiba Engagement Invitation)

مشروع دعوة خطوبة إلكترونية ملكية فاخرة باللغة العربية (RTL)، متجاوبة بالكامل لجميع شاشات الهواتف والأجهزة اللوحية والكمبيوتر، ومجهزة للنشر الفوري على منصة **Vercel**.

---

## ✨ المميزات الرئيسية للمشروع (Features):

1. **بوابة الدخول الملكية التفاعلية (Opening Gate Overlay):**
   - واجهة ترحيبية ملكية تعرض البسملة الشريفة وأسماء العروسين.
   - زر ذهبي متوهج نابض: **"✨ افتح الدعوة ✨"**.
   - حل مشكلة تقييد المتصفحات للتشغيل التلقائي للصوت (Browser Autoplay Policy)، حيث يبدأ تشغيل الأغنية `song.mp3` فور ضغط الزر من قِبل الزائر مع حركة فتح أبواب ملكية وانفجار قصاصات الزينة الاحتفالية (Confetti).

2. **التصميم الملكي الفاخر (Royal Aesthetic):**
   - لوحة ألوان راقية تجمع بين الكريمي الهادئ (`#fdf8f2`)، والوردي الناعم (`#f4e6e6`)، والذهب الميتاليك المتدرج (`#c59d5f` / `#dfba73` / `#9e783d`).
   - جزيئات ولمعان ذهبي عائم في الخلفية عبر Canvas تفاعلي خفيف وفائق السلاسة.
   - خطوط عربية ملكية من Google Fonts:
     - **Amiri**: للآيات القرآنية والاقتباسات والعبارات الشاعرية.
     - **Reem Kufi**: للعناوين الكبرى وأسماء العروسين.
     - **Cairo**: للنصوص التوضيحية والأرقام والأزرار.

3. **الآية القرآنية الكريمة:**
   - ﴿ وَمِنْ آيَاتِهِ أَنْ خَلَقَ لَكُم مِّنْ أَنفُسِكُمْ أَزْوَاجًا لِّتَسْكُنُوا إِلَيْهَا وَجَعَلَ بَيْنَكُم مَّوَدَّةً وَرَحْمَةً ﴾ بتنسيق إسلامي مذهب وزخارف ناعمة.

4. **معرض صور العروسين (Couple Arch Frames):**
   - إطارات أقواس ملكية ذهبية بمقاسات منحنية محددة (`border-radius: 120px 120px 20px 20px`) تُظهر `photo1.jpg` و `photo2.jpg` مع تأثيرات ظلال مذهبة ولمعان تفاعلي عند التمرير.

5. **تفاصيل الدعوة وكلمات الحب:**
   - شارة ملكية: "دَعْوَةُ خُطُوبَة".
   - أسماء العروسين: "أحمد ❤ حبيبة" مع نبض رومانسي ناعم.
   - عبارة الدعوة الراقية وعبارة "«شريك روحي.. وبداية رحلتنا المباركة»".

6. **العد التنازلي المباشر (Live Countdown Timer):**
   - حساب دقيق ومباشر بالأيام، الساعات، الدقائق، والثواني حتى موعد الحفل: **الأربعاء، 25 نوفمبر 2026 الساعة 7:00 مساءً**.

7. **بطاقة الموعد والمكان التفاعلية:**
   - التاريخ: يوم الأربعاء، 25 نوفمبر 2026 (07:00 م).
   - المكان: قاعة كنوز - المسبك البحري، وراق العرب، الوراق.
   - زر **"عرض الموقع على الخريطة"** يفتح مباشرة رابط Google Maps المخصص: `https://maps.app.goo.gl/VuAW5H2RXTXyENbi7?g_st=iwb`.
   - زر **"إضافة للتقويم (.ics)"** يُنشئ ويحمّل ملف تقويم قياسي متوافق مع هواتف iPhone وAndroid وGoogle Calendar لتذكير الضيوف بالموعد تلقائياً.
   - زر **"نسخ العنوان"** لنسخ اسم وعنوان القاعة بضغطة زر مع إشعار فوري (Toast).

8. **سجل التهاني والتبريكات التفاعلي (Interactive Guestbook & Blessings Wall):**
   - نموذج تفاعلي لكتابة اسم الضيف وتهنئته أو دعائه للعروسين.
   - تظهر التهاني فوراً على جدار المباركات وتُحفظ محلياً في `localStorage`.
   - إمكانية الإعجاب بكل تهنئة (زر القلب التفاعلي).

9. **وحدة التحكم في الصوت العائمة (Floating Audio Controller):**
   - زر أنيق ثابت في أسفل يسار الشاشة مع أعمدة موجات صوتية نابضة تتفاعل مع تشغيل وإيقاف الأغنية `song.mp3`.

10. **مشاركة سريعة عبر واتساب:**
    - زر مخصص لتمكين العروسين والمهنئين من مشاركة بطاقة الدعوة مع نص جذاب عبر تطبيق WhatsApp بنقرة واحدة.

## 🚀 كيفية الرفع على Vercel (Deployment on Vercel):

### الطريقة الأولى: سحب وإفلات (Drag & Drop) بدون أوامر
1. افتح حسابك على [Vercel](https://vercel.com).
2. ادخل إلى لوحة التحكم (Dashboard).
3. اسحب مجلد المشروع مباشرة وأفلته في صفحة المشاريع.
4. اضغط **Deploy** وستحصل على رابط مباشر يعمل فوراً!

### الطريقة الثانية: عبر GitHub & Vercel
1. أنشئ مستودعاً جديداً (New Repository) على GitHub باسم `ahmed-habiba-invitation`.
2. ارفع ملفات هذا المجلد إليه.
3. ادخل إلى Vercel واضغط **Add New Project** واختر المستودع، ثم اضغط **Deploy**.

### الطريقة الثالثة: عبر Vercel CLI في سطر الأوامر
```bash
npm i -g vercel
vercel
```
اتبع التعليمات البسيطة وسيقوم بنشر الموقع في ثوانٍ.
